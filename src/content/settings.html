ACM EXTENDED / REFERENCE

Addon options

Find the options used throughout this guide by their in game names.

01

Where to find an option

Open Options > Addon Options, choose the category in the table, then find the named option. Use the Server or Mission settings level for shared gameplay rules. Personal display preferences use your client settings. CBA shows when a value is forced by the mission or server.

The current build exposes switches for selected optional systems. Core circulation, respiratory and medication features do not each have an independent disable switch.
