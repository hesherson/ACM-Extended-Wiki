Color vision modes

Mode familyAvailable choices
Red–green correctionDeuteranomaly, deuteranopia, protanomaly and protanopia
Blue–yellow correctionTritanomaly and tritanopia
MonochromeAchromatopsia / monochrome

The correction applies to cues that use the shared color resolver, including supported IV, chest seal and monitor overlays. Neutral grays remain neutral. Protected warning colors receive a brightness floor so the correction does not dim them excessively.

Choose a mode using the cues you actually need to distinguish, then adjust strength. These settings affect game overlays; the wiki uses its own shared palette and night control.

Wiki controls

Use the sidebar search or the section selector to find a topic. On narrow screens, open the navigation button in the top bar. Medical term definitions work with hover, click or keyboard focus. Graphs support pointer inspection and numeric input.

Keyboard focus has a visible outline. The night control darkens backgrounds while retaining the medication card palette. Print uses dark text on a light background.
